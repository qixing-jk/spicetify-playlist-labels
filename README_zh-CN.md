# Spicetify 播放列表标签

[简体中文](README_zh-CN.md) | [English](README.md)

在 Spotify 曲目列表中直接查看每首歌出现在哪些播放列表中，并通过标签快速跳转或移除。

## 功能特性

- 在曲目列表中显示播放列表和“喜欢的歌曲”标签。
- 点击标签可快速跳转到对应播放列表。
- 可通过标签菜单移除曲目或取消喜欢。

![截图](screenshot.png)

## 安装

安装 [Spicetify](https://spicetify.app) 并从市场安装“Playlist Labels”。
